# คู่มือติดตั้ง

ใช้เวลาประมาณ 30 นาที ไม่มีค่าใช้จ่าย ไม่ต้องเช่าเซิร์ฟเวอร์

ระบบมีสองส่วน
- **หลังบ้าน** — Google Apps Script + Google Sheets ทำหน้าที่เก็บข้อมูล
- **หน้าบ้าน** — เว็บแอปในโฟลเดอร์ `web/` เปิดจากมือถือ ติดตั้งเป็นแอปได้

---

## ขั้นที่ 1 — สร้างสเปรดชีตฐานข้อมูล

1. สร้าง Google Sheets ใหม่ ตั้งชื่อเช่น `ระบบตรวจนับทรัพย์สิน PSA`
2. เปิดเมนู **ส่วนขยาย → Apps Script**
3. ลบไฟล์ `Code.gs` เดิมทิ้ง แล้วสร้างไฟล์ใหม่ให้ครบตามนี้
   โดยคัดลอกเนื้อหาจากโฟลเดอร์ `apps-script/` ของโปรเจกต์นี้

   | ไฟล์ที่ต้องสร้าง | คัดลอกจาก |
   |---|---|
   | `Schema.gs` | `apps-script/Schema.gs` |
   | `Db.gs` | `apps-script/Db.gs` |
   | `Domain.gs` | `apps-script/Domain.gs` |
   | `Api.gs` | `apps-script/Api.gs` |
   | `Import.gs` | `apps-script/Import.gs` |

4. กดบันทึก แล้วเลือกฟังก์ชัน `setupSheets` จากรายการด้านบน กด **เรียกใช้**
   ครั้งแรกจะขออนุญาตเข้าถึงสเปรดชีต ให้กดอนุญาต
5. กลับไปดูที่สเปรดชีต จะมีชีต `Assets` `Tags` `Rounds` `Scans` `Log` ถูกสร้างขึ้น

## ขั้นที่ 2 — นำเข้าทะเบียนจากชีตรายงานเดิม

ตัวนำเข้าอ่านชีตรายงานตรวจนับที่ใช้อยู่ได้โดยตรง ทั้งตารางทรัพย์สินและสินค้าคงคลัง
โดยหาหัวตารางเอง ไม่ต้องจัดรูปแบบใหม่

1. เปิดไฟล์ `Import.gs` ดูที่บรรทัด `DEFAULT_SOURCE_ID`
   ค่าเริ่มต้นชี้ไปที่ชีตรายงานประจำเดือนกันยายน ถ้าจะใช้ชีตอื่นให้ตั้งค่าที่
   **โครงการ → การตั้งค่าโครงการ → คุณสมบัติสคริปต์**
   เพิ่มคีย์ `SOURCE_SPREADSHEET_ID` แล้วใส่ไอดีของชีตนั้น
   (ไอดีคือส่วนกลางของ URL ระหว่าง `/d/` กับ `/edit`)
2. ปิดแล้วเปิดสเปรดชีตใหม่ จะมีเมนู **ตรวจนับทรัพย์สิน** เพิ่มขึ้นมา
3. เลือก **ตรวจนับทรัพย์สิน → นำเข้าทะเบียนจากชีตต้นทาง**
4. รอสักครู่ จะขึ้นข้อความบอกจำนวนรายการที่นำเข้าได้

ข้อมูลที่นำเข้าจะไปอยู่ในชีต `Assets` โดยแยกทรัพย์สินกับสินค้าคงคลัง
ด้วยคอลัมน์ `item_type` และเก็บสถานะกับความสมบูรณ์ของ TAG ตามที่ติ๊กไว้เดิม

> รันซ้ำได้เสมอ รายการที่มีอยู่แล้วจะถูกปรับปรุง ไม่เพิ่มซ้ำ
> และการผูกแท็กที่ทำไว้แล้วจะไม่ถูกลบ

## ขั้นที่ 3 — ตั้งรหัสเข้าใช้งาน

เว็บแอปต้องเปิดให้เข้าถึงแบบสาธารณะ จึงต้องมีรหัสกันคนนอกยิงข้อมูลเข้ามา

1. ใน Apps Script ไปที่ **โครงการ → การตั้งค่าโครงการ → คุณสมบัติสคริปต์**
2. เพิ่มคีย์ `ACCESS_KEY` แล้วตั้งค่าเป็นรหัสที่เดายาก เช่น `psa-hkt-2569-x7k2`
3. จำรหัสนี้ไว้ ต้องใส่ในแอปมือถือทุกเครื่อง

> ถ้าไม่ตั้ง `ACCESS_KEY` ระบบจะเปิดให้ใช้โดยไม่ตรวจรหัส
> สะดวกตอนทดสอบ แต่**ห้ามใช้แบบนี้กับข้อมูลจริง**

## ขั้นที่ 4 — เผยแพร่เป็นเว็บแอป

1. กดปุ่ม **ทำให้ใช้งานได้ → การทำให้ใช้งานได้ใหม่**
2. เลือกประเภทเป็น **เว็บแอป**
3. ตั้งค่าให้ตรงตามนี้ ถ้าผิดข้อใดข้อหนึ่งแอปมือถือจะเชื่อมต่อไม่ได้

   | ช่อง | ต้องเลือก |
   |---|---|
   | เรียกใช้ในฐานะ | **ฉัน** (อีเมลของคุณ) |
   | ผู้มีสิทธิ์เข้าถึง | **ทุกคน** |

4. กดทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

> ทุกครั้งที่แก้โค้ดฝั่ง Apps Script ต้องกด "การทำให้ใช้งานได้ใหม่" อีกรอบ
> มิฉะนั้นเซิร์ฟเวอร์จะยังใช้โค้ดเดิม

## ขั้นที่ 5 — เผยแพร่แอปมือถือ

แอปเป็นไฟล์เว็บล้วน วางบนที่ไหนก็ได้ที่เป็น **HTTPS**
(จำเป็น เพราะการอ่าน NFC และการใช้กล้องทำงานเฉพาะบน HTTPS เท่านั้น)

### วิธีที่ง่ายที่สุด — GitHub Pages

1. ในหน้า repository ไปที่ **Settings → Pages**
2. ตั้ง Source เป็น **Deploy from a branch**
3. เลือก branch ที่มีโค้ดนี้ และโฟลเดอร์ **`/web`** (ไม่ใช่ `/root`)
4. กดบันทึก รอประมาณหนึ่งถึงสองนาที จะได้ URL เช่น
   `https://sunisarabo.github.io/Asset/`

### ทางเลือกอื่น

Netlify, Cloudflare Pages, Vercel — ลากโฟลเดอร์ `web/` วางได้เลย
หรือวางบนเว็บเซิร์ฟเวอร์ภายในองค์กรที่มีใบรับรอง HTTPS

## ขั้นที่ 6 — ตั้งค่าที่มือถือ

1. เปิด URL ของแอปด้วย **Chrome บน Android**
2. ไปที่แท็บ **ตั้งค่า** แล้วกรอก
   - **ที่อยู่ Apps Script** — URL ที่ลงท้ายด้วย `/exec` จากขั้นที่ 4
   - **รหัสเข้าใช้งาน** — ค่า `ACCESS_KEY` จากขั้นที่ 3
   - **ชื่อผู้ตรวจ** และ **สถานที่ที่กำลังตรวจ**
3. กด **ทดสอบการเชื่อมต่อ** ต้องขึ้นชื่อสเปรดชีต
4. กด **ซิงก์ข้อมูลเดี๋ยวนี้** เพื่อดึงทะเบียนลงเครื่อง
5. กดเมนูของ Chrome แล้วเลือก **เพิ่มลงในหน้าจอหลัก** เพื่อติดตั้งเป็นแอป

หลังซิงก์ครั้งแรกแล้ว แอปทำงานได้เต็มรูปแบบแม้ไม่มีสัญญาณ
ผลการสแกนจะค้างในเครื่องและส่งขึ้นอัตโนมัติเมื่อกลับมามีเน็ต

## ขั้นที่ 7 — เริ่มตรวจนับ

1. หน้า **ตั้งค่า** กด **เปิดวงรอบใหม่ประจำเดือนนี้**
2. ไปหน้า **สแกน** เลือกวิธีอ่านแท็กให้ตรงกับอุปกรณ์ที่ใช้
   (ดู [HARDWARE.md](HARDWARE.md) ถ้ายังไม่แน่ใจว่าแท็กเป็นชนิดไหน)
3. เริ่มยิงแท็กได้เลย ตัวเลขด้านบนจะเดินขึ้นตามจำนวนที่พบ
4. เมื่อเจอชิ้นที่ชำรุดหรือแท็กเสีย กดปุ่มแก้สถานะใต้การ์ดผลทันที
5. หน้า **ผลตรวจ** ดูว่าเหลือชิ้นไหนยังไม่พบ และดาวน์โหลด CSV ไปทำรายงานได้

## ขั้นที่ 8 — ตั้งให้ระบบทำงานเอง (ไม่บังคับ แต่แนะนำ)

1. ในสเปรดชีต เมนู **ตรวจนับทรัพย์สิน → งานอัตโนมัติ → ตั้งให้ทำงานเอง**
   ครั้งแรกจะขออนุญาตให้สคริปต์ตั้งเวลาและส่งอีเมล กด **อนุญาต**
2. ตั้งช่องทางแจ้งเตือนอย่างน้อยหนึ่งทางใน **ส่วนขยาย → Apps Script →
   การตั้งค่าโปรเจกต์ → คุณสมบัติสคริปต์**

   | คีย์ | ค่า |
   |---|---|
   | `NOTIFY_EMAIL` | อีเมลผู้รับ คั่นหลายคนด้วยจุลภาค |
   | `CHAT_WEBHOOK` | URL ของ Google Chat incoming webhook (ถ้าใช้ Chat) |

   ถ้าไม่ตั้งเลย ระบบยังเปิดและปิดวงรอบให้ตามปกติ เพียงแต่จะไม่มีใครได้รับสรุป
3. ตรวจผลด้วย **งานอัตโนมัติ → ดูสถานะ** และกด
   **เปิดวงรอบเดือนนี้เดี๋ยวนี้** เพื่อลองให้เห็นผลทันทีโดยไม่ต้องรอถึงพรุ่งนี้

ตั้งแต่นั้นระบบจะเปิดวงรอบของเดือนใหม่เองตอนเช้าวันที่ 1 ส่งสรุปความคืบหน้า
ทุกเย็น และปิดวงรอบพร้อมออกรายงานลงชีตใหม่ในคืนวันสุดท้ายของเดือน
ปรับเวลาและเงื่อนไขทั้งหมดได้จากตารางคุณสมบัติสคริปต์ใน [README](../README.md)

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| กดทดสอบแล้วขึ้น "เซิร์ฟเวอร์ตอบกลับผิดรูปแบบ" | ตอน deploy ตั้งผู้มีสิทธิ์เข้าถึงไม่ใช่ "ทุกคน" ให้แก้แล้ว deploy ใหม่ |
| ขึ้น "รหัสเข้าใช้งานไม่ถูกต้อง" | รหัสในแอปไม่ตรงกับ `ACCESS_KEY` ใน Script Properties |
| ปุ่ม "NFC ในมือถือ" กดไม่ได้ | เครื่องไม่ใช่ Android + Chrome หรือยังไม่เปิด NFC ในตั้งค่าเครื่อง — iPhone ใช้ไม่ได้ |
| เครื่องอ่านบลูทูธยิงแล้วไม่มีอะไรเกิดขึ้น | เครื่องอ่านยังไม่อยู่ในโหมด HID หรือยังไม่ได้กดเลือกวิธีอ่าน "เครื่องอ่านบลูทูธ" ในแอป |
| สแกนแล้วขึ้น "แท็กไม่รู้จัก" ทุกชิ้น | ยังไม่ได้ผูกแท็กกับทรัพย์สิน ใช้หน้าที่เด้งขึ้นมาผูกทีละชิ้นในรอบแรก |
| ตัวเลข "รอส่ง" ไม่ลดลง | ไม่มีสัญญาณ หรือ URL เซิร์ฟเวอร์ผิด ข้อมูลยังอยู่ครบในเครื่อง กดที่ตัวเลขเพื่อลองส่งใหม่ |
| แก้โค้ด Apps Script แล้วไม่มีผล | ต้องกด "การทำให้ใช้งานได้ใหม่" ทุกครั้ง |
| ตั้งงานอัตโนมัติแล้วไม่มีอีเมลเข้า | ยังไม่ได้ตั้ง `NOTIFY_EMAIL` หรือ `CHAT_WEBHOOK` ดูที่ **งานอัตโนมัติ → ดูสถานะ** |
| วงรอบของเดือนใหม่ไม่ถูกเปิดให้ | ตรวจว่า `AUTOMATION_AUTO_OPEN` ไม่ได้ตั้งเป็น `FALSE` และเมนู **ดูสถานะ** แสดงงานที่ตั้งไว้ครบสามตัว |
| วงรอบเดือนก่อนยังค้างเปิดอยู่ | ปกติ — งานรอบถัดไปจะปิดให้เอง หรือกด **ปิดวงรอบที่ถึงกำหนดเดี๋ยวนี้** |
