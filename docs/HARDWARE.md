# เลือกอุปกรณ์อ่านแท็กให้ตรงกับแท็กที่มีอยู่

เรื่องนี้ต้องเคลียร์ก่อนอย่างอื่น เพราะ **มือถืออ่านแท็ก RFID ได้ไม่ทุกชนิด**
ถ้าเลือกผิดจะซื้ออุปกรณ์มาแล้วใช้ไม่ได้เลย

## แท็กที่มีอยู่เป็นชนิดไหน

| ลักษณะที่สังเกตได้ | ชนิด | มือถืออ่านเองได้ไหม |
|---|---|---|
| สติกเกอร์แผ่นบาง มีเสาอากาศเป็นแถบยาวคล้ายปีกผีเสื้อ ยาว 5–10 ซม. | **UHF** (EPC Gen2, 860–960MHz) | **ไม่ได้** ต้องมีเครื่องอ่านต่อพ่วง |
| สติกเกอร์หรือการ์ด มีขดลวดเป็นวงสี่เหลี่ยมซ้อนกันหลายรอบ ขนาดประมาณบัตรประชาชนหรือเล็กกว่า | **NFC / HF** (13.56MHz) | **ได้** ถ้าเป็น Android |
| เป็นบาร์โค้ดหรือ QR อย่างเดียว ไม่มีขดลวดหรือเสาอากาศ | บาร์โค้ด | ได้ ใช้กล้อง |

แท็กที่ใช้ติดครุภัณฑ์ในหน่วยงานราชการและสนามบินส่วนใหญ่เป็น **UHF**
เพราะอ่านได้จากระยะ 1–5 เมตร และกวาดได้ทีละหลายสิบชิ้น
ซึ่งเป็นเหตุผลเดียวที่ทำให้การตรวจนับเร็วขึ้นจริง

**วิธีตรวจสอบที่ชัดที่สุด** — เอามือถือ Android แตะที่แท็ก
ถ้าเครื่องสั่นหรือมีเสียงตอบ แปลว่าเป็น NFC ถ้าเงียบสนิทแปลว่าเป็น UHF

## ถ้าแท็กเป็น UHF

มือถืออ่านเองไม่ได้ ต้องใช้อย่างใดอย่างหนึ่ง

### 1. เครื่องอ่านบลูทูธต่อกับมือถือที่มีอยู่ (แนะนำ)

ต่อบลูทูธกับมือถือในโหมดคีย์บอร์ด (HID) เมื่อกดไก เครื่องจะ "พิมพ์" รหัส EPC
เข้ามาในแอปเหมือนคนพิมพ์ แอปนี้รองรับโหมดนี้อยู่แล้วโดยไม่ต้องลงไดรเวอร์เพิ่ม

| รุ่น | ระยะอ่าน | ราคาโดยประมาณ |
|---|---|---|
| Chainway R6 | 3–5 ม. | 15,000–25,000 บาท |
| TSL 1128 | 5–7 ม. | 45,000–60,000 บาท |
| Zebra RFD40 | 5–8 ม. | 50,000–70,000 บาท |

**สิ่งที่ต้องยืนยันกับผู้ขายก่อนซื้อ** — เครื่องต้องตั้งเป็นโหมด **HID / Keyboard Wedge**
ได้ บางรุ่นมาในโหมด SPP หรือบังคับให้ใช้ SDK ของยี่ห้อเท่านั้น ซึ่งจะใช้กับแอปนี้ไม่ได้

### 2. เครื่องมือถือที่มี UHF ในตัว

เป็น Android เต็มรูปแบบ เปิดแอปนี้ในเบราว์เซอร์ได้เลย
เช่น Chainway C72 / C66, Zebra TC22 ราคาประมาณ 30,000–60,000 บาท
สะดวกกว่าเพราะเป็นเครื่องเดียวจบ แต่ต้องซื้อเครื่องใหม่ทั้งเครื่อง

> เครื่องที่มี UHF ในตัวบางรุ่นส่งค่าผ่าน SDK เท่านั้น ไม่ได้ส่งเป็นคีย์บอร์ด
> ต้องตั้งค่าให้เป็นโหมด keyboard output ก่อน (ผู้ผลิตมักเรียกว่า KeyEmulator
> หรือ Scan Wedge) จึงจะใช้กับแอปนี้ได้

## ถ้าแท็กเป็น NFC

ใช้มือถือ Android ที่มีอยู่ได้เลย ไม่ต้องซื้ออะไรเพิ่ม

**ข้อจำกัดที่ต้องรู้**

- ต้องเป็น **Android + Chrome 89 ขึ้นไป** และเปิด NFC ในตั้งค่าเครื่อง
- **iPhone ใช้ไม่ได้** เพราะ Safari ไม่รองรับ Web NFC (อ่าน NFC ผ่านเว็บไม่ได้เลย)
- ต้องแตะทีละชิ้นในระยะ 1–4 ซม. เร็วกว่าการจดมือ แต่ช้ากว่า UHF มาก

## สรุปสำหรับการตัดสินใจ

1. ตรวจก่อนว่าแท็กที่ติดอยู่เป็น UHF หรือ NFC ด้วยวิธีแตะมือถือข้างต้น
2. ถ้าเป็น NFC — ใช้ Android ที่มีอยู่ เริ่มได้ทันทีโดยไม่มีค่าใช้จ่าย
3. ถ้าเป็น UHF — ซื้อเครื่องอ่านบลูทูธหนึ่งเครื่องต่อทีมตรวจหนึ่งชุด
   โดยยืนยันกับผู้ขายว่าตั้งโหมด HID ได้
4. ไม่ว่าทางไหน แอปนี้ใช้ได้ทั้งหมด ไม่ต้องแก้โค้ด

การพิมพ์รหัสเองและการอ่านบาร์โค้ดมีไว้เป็นทางสำรองเสมอ
สำหรับชิ้นที่แท็กชำรุดหรือหลุดหาย ซึ่งในทะเบียนมีคอลัมน์ "ความสมบูรณ์ของ TAG" รองรับอยู่แล้ว
