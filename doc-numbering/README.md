# ระบบรันเลขหนังสือ AOTGA HKT บน Microsoft 365

ออกเลขหนังสือบันทึกภายใน หนังสือออก-ภายนอก หนังสือรับ-ภายนอก และหนังสือเตือน
ของแผนกการโดยสาร (PS) บริการพิเศษ (SS) และติดตามสัมภาระ (BS)
ในไฟล์ Excel บน OneDrive / SharePoint แทน Apps Script ของ Google Sheets เดิม

ใช้ **Office Scripts** ซึ่งมีใน Excel บนเว็บของ Microsoft 365 แบบองค์กรอยู่แล้ว
ไม่ต้องติดตั้งอะไรเพิ่ม และไม่ต้องเปลี่ยนโครงสร้างชีตเดิม

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `เพิ่มหนังสือใหม่.ts` | ออกเลขถัดไปจากแบบฟอร์มในหน้าหลัก — ผูกกับปุ่มในหน้าหลัก |
| `ตั้งค่าระบบครั้งแรก.ts` | เตรียมไฟล์ที่ย้ายมาจาก Google Sheets — รันครั้งเดียว |

## ติดตั้ง (ประมาณ 10 นาที)

1. เปิดไฟล์ **ระบบรันเลขหนังสือ AOTGA HKT** ใน **Excel บนเว็บ** (ไม่ใช่แอป Excel บนเครื่อง)
2. แท็บ **Automate** → **New Script** → ลบโค้ดตัวอย่างทิ้ง
   แล้ววางโค้ดทั้งหมดจาก `ตั้งค่าระบบครั้งแรก.ts` → ตั้งชื่อสคริปต์ว่า **ตั้งค่าระบบครั้งแรก** → **Run**
   - ดูผลในแผงด้านขวา จะบอกว่าแก้อะไรไปบ้าง และมีเลขซ้ำตรงไหน
3. **New Script** อีกครั้ง วางโค้ดจาก `เพิ่มหนังสือใหม่.ts` → ตั้งชื่อว่า **เพิ่มหนังสือใหม่** → **Save**
4. ในแผงของสคริปต์ **เพิ่มหนังสือใหม่** กด **…** → **Add in workbook**
   จะได้ปุ่มบนชีต ลากไปวางข้างแบบฟอร์มในหน้าหลัก
5. แชร์ไฟล์ให้ทุกคนในแผนกแบบ **แก้ไขได้** คนที่มีสิทธิ์แก้ไขไฟล์กดปุ่มได้ทันที

> ถ้าไม่เห็นแท็บ Automate ให้ผู้ดูแล Microsoft 365 ขององค์กรเปิด Office Scripts ที่
> Microsoft 365 admin center → Settings → Org settings → Services → Office Scripts

## ขั้นตอนตั้งค่าครั้งแรกทำอะไรกับไฟล์

รันซ้ำได้โดยไม่เกิดผลซ้ำซ้อน และ OneDrive เก็บประวัติเวอร์ชันไว้ย้อนกลับได้เสมอ
(ไฟล์ → ข้อมูล → ประวัติเวอร์ชัน)

- **หน้าหลัก** — ช่องแผนก ประเภท และผู้บันทึกเป็นรายการให้เลือก (รายชื่อผู้บันทึกดึงจาก
  ชีต 👥 แอดมิน เพิ่มคนใหม่ที่นั่นแล้วเลือกได้เลย) เพิ่มช่อง
  *รหัสพนักงาน / เลขหนังสือต้นทาง*, *วันที่ในหนังสือ*, *หมายเหตุ / ลิงก์ไฟล์*
  และ *✅ เลขที่ได้* ใต้ช่องถึง/จาก
- **ตั้งค่า** — ปีกลายเป็นสูตร `=YEAR(TODAY())+543` และเติมตัวอย่างเลขของหนังสือรับ
  กับหนังสือเตือน (BS) ที่ยังไม่มี
- **ชีตข้อมูลทุกชีต** — วันที่ที่ปีเพี้ยนตอนนำเข้า (ปี 2569 ถูกเก็บเป็น ค.ศ. 2569
  หรือ 69 ถูกอ่านเป็น 1969) ถูกแก้เป็นวันที่จริง แล้วแสดงแบบไทย เช่น 29 ก.ย. 2569
  และลบแถวว่างที่นำเข้ามาแต่มีแค่คำว่า `NaT`
- **รายงานเลขซ้ำ** ของปีนี้ ไม่แก้ให้เองเพราะเลขเหล่านั้นออกไปแล้วจริง ต้องตรวจกับตัวหนังสือ

## วิธีใช้ประจำวัน

1. หน้าหลัก → เลือก **แผนก**, **ประเภทหนังสือ**, **ผู้บันทึก**
2. กรอก **เรื่อง** และ **ถึง/จาก**
   - หนังสือเตือน: ถึง/จาก = ชื่อพนักงาน, ช่องรหัสพนักงาน = รหัสพนักงานที่ถูกเตือน
   - หนังสือรับ: ถึง/จาก = หน่วยงานที่ส่งมา, ช่องเลขต้นทาง = เลขที่ในหนังสือที่รับ,
     ใส่วันที่ในหนังสือ และวางลิงก์ไฟล์สแกนในหมายเหตุ
3. กดปุ่ม **เพิ่มหนังสือใหม่** → เลขที่ได้ขึ้นที่ช่อง **✅ เลขที่ได้**
   และบันทึกลงชีตของแผนก/ประเภทนั้นกับ 📊 Master Log ให้เอง

ถ้ากรอกไม่ครบ ช่อง ✅ เลขที่ได้ จะขึ้นข้อความ ❌ บอกว่าขาดอะไร และจะไม่ออกเลข

## รูปแบบเลขหนังสือ

| ประเภท | PS | SS | BS |
|---|---|---|---|
| บันทึกภายใน (IN) | AOTGA/OS-HKT/001/2569 | AOTGA/OSS-HKT/001/2569 | AOTGA/LL-HKT/001/2569 |
| หนังสือออก-ภายนอก (OUT) | AOTGA/HKT-OS/001/2569 | AOTGA/HKT-OSS/001/2569 | AOTGA/HKT-LL/001/2569 |
| หนังสือรับ-ภายนอก (RECV) | รับเลข 001/2569 (OS) | รับเลข 001/2569 (OSS) | รับเลข 001/2569 (LL) |
| หนังสือเตือน (WARN) | AOTGA-OS-HKT-OSW-001-2569 | AOTGA-OSS-HKT-OSSW-001-2569 | AOTGA-LL-HKT-LLW-001-2569 |

แก้รูปแบบได้ที่ชีต ⚙️ ตั้งค่า โดยพิมพ์ตัวอย่างของเลขแรกของปี (ต้องมี `001` และปี พ.ศ.)
สคริปต์จะอ่านรูปแบบจากตัวอย่างนั้นเอง

**กติกาการนับเลข**

- เลขถัดไป = เลขสูงสุดของปีนี้ที่มีอยู่ในชีตนั้น + 1 นับจากเลขที่ปรากฏในชีตจริง
- ปีในเลขคือปี พ.ศ. ของวันที่กดออกเลข ตามเวลาประเทศไทย **ขึ้นปีใหม่แล้วเริ่ม 001 เอง**
  ไม่ต้องสร้างชีตใหม่ ถ้าต้องการแยกชีตปีเก่าเก็บไว้ ให้คัดลอกแถวไปชีตสำรอง (เช่น `… 2569`)
- **ยกเลิกเลข** ให้เปลี่ยนสถานะเป็น `ยกเลิก` แทนการลบแถว เลขนั้นจะไม่ถูกนำกลับมาใช้
  (ถ้าลบแถวที่เป็นเลขสูงสุดทิ้ง เลขนั้นจะถูกออกซ้ำให้คนถัดไป)

## ข้อจำกัดที่ควรรู้

- **ใช้ใน Excel บนเว็บ** — Office Scripts ไม่ทำงานในแอป Excel บน Windows/Mac รุ่นเก่า
  (Microsoft 365 รุ่นล่าสุดบน Windows เริ่มรองรับแล้ว แต่บนเว็บแน่นอนที่สุด)
- **กดพร้อมกัน** — สคริปต์เขียนแถวแล้วอ่านกลับมาตรวจ ถ้าถูกคนอื่นเขียนทับหรือได้เลขชนกัน
  จะขยับไปเลขถัดไปให้เอง ป้องกันกรณีทั่วไปได้ แต่ไม่ใช่การล็อกแบบฐานข้อมูล
  ถ้าวันไหนมีหลายคนออกเลขพร้อมกันบ่อย ให้ตรวจเลขซ้ำด้วยการรัน **ตั้งค่าระบบครั้งแรก** อีกครั้ง
  (รันซ้ำได้ ส่วนที่ทำไปแล้วจะไม่ทำซ้ำ และจะรายงานเลขซ้ำให้)
- ชื่อชีตต้องคงรูปแบบเดิม เช่น `📥 บันทึกภายใน (PS)` และหัวคอลัมน์แถวที่ขึ้นต้นด้วย `ลำดับ`
  ต้องคงชื่อเดิม (ย้ายลำดับคอลัมน์ได้ สคริปต์จับคู่ด้วยชื่อหัวคอลัมน์)
