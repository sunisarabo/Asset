# ระบบตรวจนับทรัพย์สินด้วยแท็ก RFID ผ่านมือถือ

ตรวจนับทรัพย์สินและสินค้าคงคลังของแผนกการโดยสาร ท่าอากาศยานภูเก็ต
โดยใช้แท็ก RFID ที่ติดไว้อยู่แล้ว สแกนด้วยมือถือ แล้วออกรายงานในรูปแบบเดิมที่ใช้อยู่

## เรื่องที่ต้องรู้ก่อน

**มือถืออ่านแท็ก RFID ได้ไม่ทุกชนิด**

- **แท็ก NFC/HF (13.56MHz)** — มือถือ Android อ่านได้เลย ไม่ต้องซื้ออุปกรณ์เพิ่ม
- **แท็ก UHF (860–960MHz)** — ชนิดที่ใช้ติดครุภัณฑ์มากที่สุด มือถืออ่านตรง ๆ **ไม่ได้**
  ต้องต่อเครื่องอ่านบลูทูธ หรือใช้เครื่อง Android ที่มี UHF ในตัว

ระบบนี้รองรับทั้งสองแบบในแอปเดียว รวมทั้งบาร์โค้ดและการพิมพ์รหัสเอง
ดูวิธีตรวจสอบว่าแท็กที่ติดอยู่เป็นชนิดไหน และรุ่นเครื่องอ่านที่ใช้ได้
ที่ [docs/HARDWARE.md](docs/HARDWARE.md)

## ความสามารถ

- **สแกนได้สี่ทาง** — เครื่องอ่าน UHF บลูทูธ (โหมดคีย์บอร์ด), NFC ในมือถือ,
  บาร์โค้ด/QR ผ่านกล้อง และพิมพ์รหัสเองเมื่อแท็กหาย
- **ทำงานได้ขณะออฟไลน์** — ห้องเก็บของและพื้นที่หวงห้ามมักไม่มีสัญญาณ
  ทะเบียนถูกดึงมาเก็บในเครื่อง ผลสแกนคิวไว้แล้วส่งอัตโนมัติเมื่อกลับมามีเน็ต
- **บอกผลทันทีที่ยิง** — พบแล้ว / อยู่ผิดที่ / แท็กไม่รู้จัก พร้อมเสียงและแรงสั่นต่างกัน
  เพื่อให้รู้ผลโดยไม่ต้องละสายตาจากของ
- **บันทึกสถานะตามแบบฟอร์มเดิม** — สมบูรณ์ / ชำรุด / สูญหาย / เตรียมโอนย้าย /
  เตรียมจำหน่าย / ส่งซ่อม / อื่นๆ และ **ความสมบูรณ์ของ TAG** แยกต่างหาก
- **ผูกแท็กกับทรัพย์สิน** — สแกนแท็กที่ยังไม่รู้จัก ระบบเปิดหน้าผูกให้ทันที
- **รายงานสรุป** — แยกตามสถานที่ ดูว่าห้องไหนตรวจครบแล้ว ดาวน์โหลด CSV
  ที่เปิดใน Excel ภาษาไทยได้ทันที
- **ติดตั้งเป็นแอปบนมือถือได้** — เป็น PWA เพิ่มลงหน้าจอหลักแล้วใช้เหมือนแอปทั่วไป

## โครงสร้างระบบ

```
มือถือ (PWA)  ──POST──▶  Apps Script /exec  ──▶  Google Sheets
   │                                                  │
   └── IndexedDB เก็บทะเบียนและคิวผลสแกนไว้ใช้ตอนออฟไลน์
```

ไม่มีเซิร์ฟเวอร์ให้ดูแล ไม่มีค่าใช้จ่ายรายเดือน ข้อมูลอยู่ใน Google Sheets
ที่เจ้าหน้าที่เปิดดูและแก้ไขเองได้ตามปกติ

## ติดตั้ง

ดู [docs/SETUP.md](docs/SETUP.md) — ใช้เวลาประมาณ 30 นาที

## ทดลองก่อนติดตั้ง

เปิด `web/index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ แล้วเปิด **โหมดสาธิต**
ในหน้าตั้งค่า จะมีข้อมูลจำลอง 25 รายการจากทะเบียนจริงให้ทดลองสแกน
โดยไม่ต้องต่อ backend

```bash
npx http-server web -p 8080
# เปิด http://localhost:8080 → ตั้งค่า → เปิดโหมดสาธิต
```

ในโหมดสาธิตจะมีปุ่ม **สุ่มแท็กสาธิต** ในหน้าสแกน ใช้จำลองการยิงแท็กได้

## ทดสอบ

```bash
npm test                                # ตรรกะนำเข้าและตรรกะเทียบผล (ไม่ต้องติดตั้งอะไร)

npm install --no-save playwright        # เฉพาะครั้งแรก
npx playwright install chromium
node test/smoke.mjs                     # การใช้งานจริงบนเบราว์เซอร์
```

`test/smoke.mjs` จำลองหน้าจอมือถือขนาด 390×844 เดินตามเส้นทางที่ผู้ตรวจใช้จริง
ตั้งแต่สแกน แก้สถานะ ผูกแท็ก จนถึงดูรายงาน และตรวจว่าหน้าจอไม่ล้นแนวนอน

ทั้งสองชุดรันอัตโนมัติบน GitHub Actions ทุกครั้งที่เปิดหรืออัปเดต pull request
และทุกครั้งที่รวมเข้า `main` ดูที่ [`.github/workflows/test.yml`](.github/workflows/test.yml)

## ข้อควรระวัง

- เว็บแอปต้องเปิดผ่าน **HTTPS** เท่านั้น การอ่าน NFC และการใช้กล้องจะไม่ทำงานบน HTTP
- **iPhone อ่าน NFC ผ่านเว็บไม่ได้** Safari ไม่รองรับ Web NFC
  ถ้าต้องใช้ iPhone ให้ใช้เครื่องอ่านบลูทูธหรือกล้องอ่านบาร์โค้ดแทน
- Apps Script web app ต้อง deploy แบบ **ผู้มีสิทธิ์เข้าถึง = ทุกคน**
  จึงต้องตั้ง `ACCESS_KEY` ใน Script Properties เสมอก่อนใช้กับข้อมูลจริง
- ตรรกะเทียบผลถูกเขียนไว้สองที่คือ `apps-script/Domain.gs` และ `web/js/reconcile.js`
  เพราะเครื่องต้องตัดสินผลเองได้ขณะออฟไลน์ **แก้ที่ใดต้องแก้อีกที่ให้ตรงกัน**
